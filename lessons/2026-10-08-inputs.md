# Inputs with input()

Inputs let a parent pass data into a child component, so you can build one reusable component and feed it different values. In the child, declare an `input()` and read it like a function in the template.

```ts
import { Component, input } from '@angular/core';

@Component({
  selector: 'app-user-card',
  template: `<div class="card">Hi, {{ name() }}!</div>`,
})
export class UserCard {
  name = input.required<string>();
}
```

```html
<!-- parent template -->
<app-user-card name="Ada" />
<app-user-card name="Grace" />
```

## On screen

On screen you'd see two matching cards, one saying "Hi, Ada!" and the other "Hi, Grace!", from the same component showing different data. To pass one of the parent's own properties, use property binding, like `[name]="currentUser"`. You'll also see the older `@Input() name = '';` decorator in a lot of code. It does the same job, but `input()` is the newer way, built on signals.
