# Angular Lessons

One Angular tip per day.

## Layout

- `lessons/YYYY-MM-DD-topic-slug.md`: one lesson per day, with the tip text, a code snippet and a description of what you see on screen.
- `images/`: the lesson's mockup image, named to match its lesson file (for example `images/2026-09-27-topic-slug.png`), and linked from the lesson.
